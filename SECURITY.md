# Reportar un problema de seguridad

Si una instrucción, enlace o archivo del repositorio podría provocar exposición de secretos, acciones no autorizadas o daños en un sistema real, escribe a **[devcharlying@gmail.com](mailto:devcharlying@gmail.com?subject=Reporte%20de%20seguridad%20-%20Security%20Regression%20Guard)**. Se aceptan reportes en español e inglés.

No publiques credenciales, datos personales, objetivos explotables ni pruebas de concepto contra terceros en una issue o PR. Para errores de documentación sin información sensible puedes usar las [issues](https://github.com/elpeakyblinder/security-skill/issues/new/choose).

## Qué incluir

- Versión o commit de la skill y archivo o apartado afectado.
- Descripción del riesgo y pasos mínimos de reproducción con datos sintéticos.
- Agente, modelo y configuración relevantes, si se reprodujo con ellos.
- Resultado observado, alcance estimado y posible corrección, si la conoces.

No necesitas demostrar el problema sobre producción ni acceder a sistemas ajenos. Esta política no concede autorización para pruebas sobre infraestructura del autor o de terceros. Si descubriste una vulnerabilidad en otro proyecto, sigue también su canal de reporte.

## Qué esperar

El mantenimiento se realiza según disponibilidad, sin plazos de respuesta garantizados ni programa de recompensas anunciado. Se evaluará el reporte y se podrá solicitar contexto adicional. Coordina la publicación de detalles sensibles para evitar exponer sistemas o personas mientras se revisa el problema.

La revisión se centra en `main` y en la versión publicada más reciente. No se promete mantenimiento de ramas antiguas ni que una versión esté libre de vulnerabilidades. Consulta [CHANGELOG.md](CHANGELOG.md) y las [releases](https://github.com/elpeakyblinder/security-skill/releases) para conocer cambios publicados.

No envíes secretos por correo. Si necesitas compartir material sensible, solicita primero un medio adecuado. Esta política no sustituye el [aviso de responsabilidad](README.md#aviso-de-responsabilidad).
